# store-assets — Google Play listing kit

Everything needed to fill in the Play Console store listing for KANAKANJI
(`com.kanakanji.app`). Nothing in this folder ships inside the app.

## File → Play Console quick reference

| File | Where it goes in Play Console |
|---|---|
| `listing/listing-en.md` | Grow → Store presence → Main store listing (default language, English) — App name / Short description / Full description |
| `listing/listing-ja.md` | Same page → Add language: 日本語 (Japanese) |
| `listing/listing-es.md` | Same page → Add language: Español |
| `listing/listing-zh.md` | Same page → Add language: 简体中文 (Simplified Chinese) |
| `feature-graphic.png` (1024×500) | Main store listing → Graphics → Feature graphic |
| `screenshots/*.png` (1080×1920) | Main store listing → Graphics → Phone screenshots (up to 8; order shown = upload order) |
| `../PRIVACY.md` | App content → Privacy policy — **host it at a public URL first** (e.g. the repo's raw GitHub URL once pushed) and paste that URL; Play Console takes a URL, not a file |
| `data-safety-notes.md` | App content → Data safety — draft answers to the questionnaire (answered in the console, nothing uploaded) |

App icon: Play Console requires a separate 512×512 icon upload (Main
store listing → Graphics → App icon). Use
`public/icons/icon-512.png` from the repo (generated by
`npm run assets:icons`).

capture the same routes at a 1080×1920 viewport.

## Regenerating the feature graphic

```
node store-assets/scripts/generate-feature-graphic.mjs
```

Requires `@resvg/resvg-js` (already a devDependency). The script reads
the app's real stroke data for the brush "あ" mark and mirrors the app
icon's design language (see comments in the script).

## Listing copy rules of thumb

- Play limits: app name ≤ 30 chars, short description ≤ 80, full
  description ≤ 4000. Every file in `listing/` is verified under these
  limits (counts noted inline).
- The copy makes only claims verified against the source: fully offline,
  no ads, no accounts, no data collection, 92 kana + 2,136 jōyō kanji,
  SRS review, en/es/zh UI. If features change, update all four files
  together.
