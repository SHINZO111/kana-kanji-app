# Google Play 商店信息 — 简体中文 (zh-CN)

在 Play Console → 拓展业务 → 商店发布 → 主要商店信息 中添加"简体中文"
作为商店信息语言后，将以下各部分粘贴到对应字段。

## 应用名称(30 字符以内)

```
KANAKANJI 假名汉字笔顺练习
```
(18 字符)

## 简短说明(80 字符以内)

```
临摹平假名、片假名和常用汉字笔顺，完全离线，无广告无账号。
```
(29 字符)

## 完整说明(4000 字符以内)

```
KANAKANJI 是一款完全离线的日语书写练习应用 — 从你学习的第一个平假名，
到日常日语中使用的全部 2,136 个常用汉字(常用漢字)。

可以练习什么
• 全部 92 个假名 — 每一个平假名和片假名
• 全部 2,136 个常用汉字 — 日本学校教学的官方汉字表，按小学年级(1–6 年级)
  分组，另加其余常用汉字
• 每个汉字的音读、训读、含义和常用例词，数据来自专业日英词典应用
  所使用的同一批开放词典资源

如何学习
• 笔顺临摹 — 先观看字符真实笔顺的动画演示，再用手指或鼠标亲自临摹。
  笔画顺序错误或形状不对时会立即得到纠正。
• 练习集 — 按平假名、片假名或按年级分组的汉字进行练习，节奏由你掌握。
• 间隔重复复习(SRS) — 练习过的字符会在你快要遗忘时准时出现在复习中，
  让学习时间花在真正需要巩固的字符上，而不是你早已熟记的内容。
• 进度跟踪 — 一目了然地查看每个字符、每个类别的掌握程度，以及整体
  完成率。
• 搜索与浏览 — 通过字符本身、读音或英文含义直接查找任何假名或汉字。

为隐私而设计
KANAKANJI 完全在你的设备上运行:
• 安装后 100% 离线可用 — 学习无需联网，没有等待服务器的加载转圈
• 无账号、无注册、无登录
• 无广告
• 无统计分析、无跟踪器、不收集任何数据 — 你的练习记录永远不会离开
  你的设备
• 无应用内购买

完整细节见应用内的隐私页面和本商店页的"数据安全"部分 — 两者描述的
内容完全一致，因为没有更多需要披露的事项。

界面语言
应用界面支持英语、西班牙语(Español)和简体中文。汉字的读音和含义在
所有界面语言下显示一致。

适合谁使用
无论你是刚从 あ、い、う、え、お 开始的零基础学习者，还是正在备考
JLPT N2/N1 汉字的进阶学习者，KANAKANJI 都为你提供一个专注、安静的
练习环境，帮你真正建立笔顺的肌肉记忆 — 没有需要维持的打卡连胜，
没有社交动态，没有订阅。只有字符、笔画和踏实的练习。

笔顺数据与词典条目来自成熟的日语开放资源(animCJK、hanzi-writer-data-jp
项目、KANJIDIC2 和 JMdict);完整的来源署名与许可信息见应用内的
"致谢"页面。
```
